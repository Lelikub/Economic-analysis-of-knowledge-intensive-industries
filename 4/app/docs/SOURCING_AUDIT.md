# Проверка совпадения графиков снабжения

По запросу пользователя повторно проверены постановки, режимы переменных, два отдельных CSV потоков и визуализация. Расчётной ошибки не обнаружено.

Разрешение дробить спрос не обязывает модель дробить его. Оптимум базовой модели сам удовлетворяет ограничению единственного источника. При сужении допустимой области оптимум минимизации не может улучшиться; поскольку исходный оптимум остаётся допустимым, он сохраняется. В обоих случаях открыты B — Тверь, C — Рязань, D — Великий Новгород; стоимость123624000рублей/год, фиксированная часть104000000, транспорт19624000.

Независимые проверки:

- перебор всех16наборов открытий и транспортная линейная модель SciPy/HiGHS;
- полный перебор4^5=1024назначений для одного источника;
- нижняя граница по каждому набору: постоянные затраты плюс тарифный минимум для каждого клиента без ограничения мощностей. Базовый допустимый план достигает глобального минимума этих границ;
- баланс спроса, мощности, бинарные назначения, максимальная разность потоков между моделями0тонн/год.

Для контроля различия моделей только в памяти уменьшена мощность B — Тверь с700до650тонн/год. Тогда модель с дроблением даёт124021000рублей/год, без дробления128070000. Разница4049000рублей/год. В первой модели Зеленоград получает410тонн из Твери и10из Рязани; Дубна240из Твери и20из Великого Новгорода. Во второй весь спрос Дубны260тонн поставляется из Великого Новгорода. Оба оптимума независимо подтверждены.

Реализация проверки: src/calculators/sourcing_audit.py; экспорт output/sourcing_audit.json, полные значения также в metrics.json. Регрессия test_multi_and_single_can_differ_when_capacity_requires_split подтверждает наличие дробления в первой модели и его отсутствие во второй. В отчёте сохранены базовые графики и добавлено объяснение, диагностический сценарий явно отделён от первичных данных.

По дополнительному указанию пользователя удалены принудительные разрывы страниц, кроме разрыва после титула. Заголовки, рисунки и подписи сохраняют естественные правила переносов.
