# Практическое занятие № 2: OPEX, энергетика и эксергия

Расчётный проект находится целиком в `2/app`. Входы расположены в `2/data`, задание, лекция 3 и шаблон Word — в `2/task`.

## Запуск

Из каталога `2/app`:

```powershell
..\..\.venv\Scripts\python.exe -m pip install -r requirements.txt
..\..\.venv\Scripts\python.exe -m pytest -q
..\..\.venv\Scripts\python.exe main.py
```

Итоговые файлы появятся в `results` и `logs`. `main.py` читает исходные файлы, вычисляет метрики Python-кодом, запускает расчётные тесты, сравнивает результаты с эталонами и формирует Excel и Word. Excel использует русские названия листов и таблиц. Word создаётся из предоставленного шаблона.

Статус `SKIPPED_MISSING_INPUT` означает, что для проектного численного значения не хватает исходного параметра; нуль вместо отсутствующих данных не подставляется. В `results/issues_and_assumptions.md` перечислены ограничения и расхождения источников.
